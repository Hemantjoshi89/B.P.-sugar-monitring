BP & Sugar Monitoring System

BP & Sugar Monitoring System is a healthcare web application that helps users track blood pressure and sugar levels from home. The project is built using React.js and focuses on simple health monitoring, record management, and progress tracking.

Features
- Store BP and sugar records
- View previous health data
- User-friendly interface
- Future AI-based health insights
- Medicine reminder support

Technologies Used
- React.js
- JavaScript
- HTML
- CSS

Project Goal
The goal of this project is to create a simple and useful healthcare solution that helps people monitor their health regularly from home.
